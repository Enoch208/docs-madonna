---
title: "Glossary"
description: "A plain-language reference for the terms used throughout Spoke."
---

| Term              | Meaning                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------- |
| Allocation        | A sale's reward amount assigned to one eligible contributor                                   |
| Attribution       | The link and path associated with a purchase                                                  |
| Basis point       | One-hundredth of a percent; 10,000 basis points equals 100%                                   |
| Buyer payment     | The amount paid for the product, accounted separately from rewards                            |
| Campaign          | A merchant's published product offer, funding, schedule, and reward policy                    |
| Claim             | A beneficiary's withdrawal of a claimable contract balance                                    |
| Commission policy | The rate, caps, weights, eligibility depth, short-path rule, and hold governing rewards       |
| Direct purchase   | A purchase with no distributor node; represented by node ID 0                                 |
| Distributor       | A person who shares a campaign through an attributable link                                   |
| Finalization      | The onchain action after the hold that makes sale obligations claimable                       |
| Hold              | The period before unlock during which a pending sale can be refunded                          |
| Indexer           | The service that observes chain events for application read models                            |
| Liability         | Reward funds committed to accepted sales or beneficiaries                                     |
| Merchant          | The party providing the product and funding its distribution rewards                          |
| Node              | A sharing link with an owner, campaign, and fixed parent                                      |
| Order key         | A client-generated identifier for one logical purchase                                        |
| Paid path         | The eligible, bounded ancestry used to allocate a sale's reward                               |
| Policy hash       | A commitment to the exact accepted policy terms                                               |
| Projection        | A derived database view built from canonical chain events                                     |
| Receipt           | A record of a purchase, allocation, settlement state, and proof                               |
| Reorganization    | A change to canonical chain history requiring index reconciliation                            |
| Reward budget     | Merchant-provided funds available to reserve for qualifying sales                             |
| SDUSD             | Spoke's six-decimal, freely mintable, non-redeemable testnet token                            |
| Short path        | A sale with fewer eligible contributors than the policy's paid depth                          |
| Unlock time       | The boundary before which a pending sale may refund and at/after which it may finalize        |
| Unused budget     | Reward funds that are not reserved or claimable and may be withdrawn under the campaign rules |
| Vault             | The merchant-facing view of campaign reward funds and obligations                             |
