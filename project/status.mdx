**Reviewed 15 October 2026.** The web app and API are deployed at [usespoke.xyz](https://usespoke.xyz). Commerce uses non-redeemable SDUSD on Monad Testnet. Demo mode is a separate labelled fixture experience; mainnet Aurora funding stays separate from commerce.

## Shipped product capabilities

| Area              | Implemented behavior                                                                                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Merchant commerce | Merchant setup, immutable product versions, campaign publication/funding, checkout, buyer-only delivery, refunds and claims                                       |
| Partner workflow  | Privacy-aware discovery and comparison, invitations with current terms, acceptance and independently approved link creation; Joined follows confirmation/indexing |
| Partner Passport  | Settlement-month contribution history, receipt evidence, campaign positions, public sharing and owner-only claimable/claimed rewards                              |
| Live network      | Expandable branches, ancestry, allocation paths, 30-day growth, paginated confirmed activity, receipt links and checkpoint freshness                              |
| External research | Merchant-triggered Nansen transaction, first-funder and Monad relationship research with evidence, freshness, privacy and durable credit limits                   |
| Mera account UX   | Passkey-first entry, support/cancellation guidance, original campaign/referral return context and bounded testnet gas assistance                                  |
| Email onboarding  | Reown one-time-code email login and embedded wallets, kept distinct from Mera accounts                                                                            |
| Private workspace | Separate PRF encryption namespace, ciphertext-only sync, revision conflicts, original local-note preservation and encrypted backups                               |
| Infrastructure    | Envio ingestion, canonical verification/replay, atomic projection, reorg recovery, endpoint schemas and freshness reporting                                       |

The shared contract contains **194 client methods**: **140 core**, **4 optional mainnet funding**, and **50 designed unavailable** methods. Unsupported methods return `FEATURE_NOT_AVAILABLE`. Authentication, ownership, runtime configuration and quotas still apply to core methods.

## Evidence and limits

The updated application passed **717 tests across 76 files** with PostgreSQL and both required Anvil chains, plus typecheck, lint, formatting and a production build. The unchanged settlement contract baseline passed **33 Foundry tests**. [CI](https://github.com/Enoch208/spoke/actions/workflows/ci.yml) records validation per pushed revision.

The [recorded testnet journey](/project/proof) has inspectable purchases, refunds, settlements and claims. Passport and network pages display those canonical events. They are scripted demonstrations, not customer revenue or adoption.

Nansen research includes a genuine external public-wallet sample with 100 recent transactions across seven networks, first funding and Monad relationship evidence. That address is not a Spoke partner. New seeded Spoke wallets may have no observed mainnet history.

Passkey UI and cryptographic/API behavior are tested, but physical cross-device PRF restoration and a new device-specific passkey transaction remain human verification tasks. The workspace does not claim universal recovery. Mainnet commerce, independent audit and production-scale capacity validation remain future gates.

## Developer distribution

The public SDK exposes 32 credential-free read methods. The [0.1.3 GitHub archive](https://github.com/Enoch208/spoke/releases/tag/sdk-v0.1.3) updates Passport and activity schemas and passes isolated packed installation, ESM/CommonJS, consumer typechecks and live API reads. The same version is published on npm as `@enochid/spoke-sdk@0.1.3`, with package integrity matching the GitHub archive. The generated API reference describes all 194 methods and identifies its source commit.

## Remaining designed surfaces

Communities, teams, API-key management, webhooks, external commerce connectors and other extension methods remain designed or Demo-only where the registry says unavailable. Invitations and partner discovery are already live and are not part of that preview list.
