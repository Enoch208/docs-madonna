| Area               | Implemented behavior                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Discovery          | Public campaigns, merchant profiles, products, policies, and distributor views                                   |
| Merchant workflow  | Merchant setup, product versions, campaign preparation, funding, publication, and vault views                    |

## Implemented with a narrower or conditional scope

**Aurora funding:** code and UI are deployed, but configuration is disabled and a real mainnet transfer has not been verified. It is separate from testnet settlement.

**Nansen insights:** cached supported-mainnet history is integrated. Seeded demonstration wallets currently have no observed history. It does not prove customer revenue or determine payouts.

**Public SDK:** [`@enochid/spoke-sdk` version 0.1.2](https://www.npmjs.com/package/@enochid/spoke-sdk) is published on npm with 32 public read methods, ESM/CommonJS builds, and TypeScript declarations. A matching [GitHub release archive](https://github.com/Enoch208/docs-madonna/releases/tag/sdk-v0.1.2) provides a checksum and release notes. Authenticated writes remain outside this read SDK.

**Account onboarding:** settings and recovery surfaces exist; further cross-device progress persistence and onboarding polish remain.

## Demo or designed, not live commitments

Additional invitation/community flows, partner discovery and recommendations, team/API-key management, commerce connectors, webhooks, buyer incentives, advanced growth analytics, and other extension surfaces have designs or Demo presentations. Check the method-level registry before building against them.

At this release, the shared contract contains **189 client methods**: **135 core live**, **4 optional mainnet funding**, and **50 unavailable-by-design** methods. Unsupported methods intentionally return `FEATURE_NOT_AVAILABLE`.

## Documentation and SDK releases

The hosted documentation is live at [docs.usespoke.xyz](https://docs.usespoke.xyz). Its expanded reference covers all 189 client methods; that is broader than the 32 public methods exposed by the SDK. The SDK is versioned separately from the deployed application, so publishing it does not change the settlement deployment described above.

## Evidence and verification

The recorded production journey contains **15 confirmed testnet transactions** covering campaign setup, links, purchase, delivery access, refund and access revocation, finalization, and claims. The broader scripted settlement fixture records **58 confirmed transactions**, including gas top-ups.

The application's [release CI](https://github.com/Enoch208/spoke/actions/runs/38371406203) completed successfully. The release's frontend validation included **494 tests across 42 files**, type checks, lint, formatting, and a production build. Tests and source verification do not substitute for an independent audit.
